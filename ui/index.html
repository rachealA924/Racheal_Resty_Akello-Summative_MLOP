1. Upload new labelled data

Pick several images and their class, or upload a .zip with one folder per class (CBB/, CBSD/, CGM/, CMD/, Healthy/). Each image is checked, saved and recorded in the database.

2. Retrain the model

Retraining loads the current model and fine tunes it on the new images plus a sample of old ones, then compares old and new on the test set. The new model is only promoted if it is not worse.
